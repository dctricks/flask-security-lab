# Flask Security Lab

A Python and Flask-based security learning project focused on secure web application development, network service detection, and defensive security testing.

## Features

- Flask web application
- Safe subprocess-based command execution
- Input validation
- Local TCP port scanning
- Service detection
- HTTP service detection
- HTTP status reporting
- Security-focused testing in a controlled local environment
